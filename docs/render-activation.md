# تشغيل معيار على Render

فُعّل Blueprint باسم `miyar-enterprise` في **My Workspace** بتاريخ **13 سبتمبر 2026**. الخادم `miyar-enterprise-api` بحالة **Live** ومتصل بقاعدة `miyar-enterprise-db` في فرانكفورت، PostgreSQL 17. تنتهي النسخة المجانية الحالية لقاعدة البيانات في **13 أكتوبر 2026**.

## روابط التشغيل

- [تطبيق معيار المؤسسي](https://miyar-enterprise-api.onrender.com/): الواجهة والخادم من العنوان نفسه.
- [الموقع الأصلي](https://adeebnoor.github.io/Miyar/): مرتبط بعنوان الخادم تلقائيًا.
- [إدارة الخادم في Render](https://dashboard.render.com/web/srv-dajamnvqj5pc73csdq4g).

مرّر Render رابط قاعدة البيانات داخليًا، وولّد مفتاح الجلسات ومفتاح إيصالات الاعتماد وكلمة المرور الأولية تلقائيًا. لا توجد مفاتيح سرية في المستودع ولا حاجة لإرسالها في المحادثة.

النشر التلقائي مرتبط بالفرع `main` بعد نجاح الفحوص. لا حاجة لإنشاء Blueprint آخر أو قاعدة بيانات جديدة.

## أول دخول

افتح تطبيق معيار واختر **تسجيل الدخول للمؤسسة**. حساب المسؤول هو `admin@miyar.example`؛ هذه هوية دخول أولية وليست صندوق بريد. تجد كلمة المرور الأولية في متغير `MIYAR_BOOTSTRAP_PASSWORD` ضمن **Environment** للخادم؛ أدخلها في معيار مباشرة، ثم غيّرها من **الاتصال والإعدادات ← تغيير كلمة المرور**. إعادة النشر لا تعيد تعيين كلمة مرور الحساب الموجود، ولا يغيّر تعديل متغير التهيئة كلمة المرور بعد إنشاء الحساب.

لا يدخل حساب ChatGPT إلى معيار تلقائيًا. ينشئ مسؤول معيار حسابات منفصلة لأصحاب مراحل الاعتماد، ويعتمد إطار تقييم الجهة قبل تشغيل اعتماد فعلي.

## التحقق بعد التفعيل

- أعاد [فحص الصحة](https://miyar-enterprise-api.onrender.com/health) الحالة `ok` والإصدار `4.1.1` والتخزين `postgresql` وعدد المهن `5041`.
- أعاد مسار `/api/v1/signing/public-key` مفتاحًا عامًا من نوع `Ed25519`، ورفض مسار المناصب الوصول دون تسجيل دخول بالحالة `401`.
- نجح فحص CORS من عنوان GitHub Pages، وتحميل الواجهة والخط العربي وإعداد الاتصال من العنوان نفسه. لم تظهر أخطاء في سجلات التشغيل عند التحقق.
- اجتاز الإصدار 47 اختبار واجهة و25 اختبار خادم في GitHub Actions، وتشمل اختبارات الخادم قاعدة PostgreSQL والاعتمادات المتزامنة.
- افتح **جاهزية العرض** بعد الدخول للتحقق من خدمات التصدير والتوقيع.
- جرّب طلبًا توضيحيًا بحسابات المراجعين، وافحص التصدير وسجل الاعتماد.
- المطابقة الدلالية معطلة في إعداد الذاكرة المجاني الحالي. تكاملات HRIS والمنصات الوطنية تتطلب بيانات اتصال مصرحًا بها.

فحوص التشغيل العامة لا تعادل تجربة اعتماد كاملة بحسابات المؤسسة الحقيقية. قبل العرض، أكمل أول دخول، وأنشئ حسابات المراجعين واعتمد إطار تقييم الجهة. افتح التطبيق قبل العرض بوقت كافٍ لأن الخدمة المجانية قد تبدأ ببطء بعد الخمول، وخطّط لاستمرار قاعدة البيانات قبل تاريخ انتهائها.
