# Miyar QA hardening — 15 September 2026

This branch applies the urgent implementation findings from the independent QA review on top of Miyar 5.0.

## Release blockers addressed

- Institution-profile API routes stay ahead of the static `/` UI mount when `MIYAR_SERVE_UI=true`.
- Strategic Engine recommendations can be carried into Position Design / OD rather than opening an empty request.
- The quick five-role engine falls back to the full bundled SSCO directory when a direct sample match is unavailable.
- OD reference queries distinguish specialist roles from management roles and include healthcare and sales families.
- Compensation and manpower validation does not leave stale results visible beside an error.
- Key validation messages are localized in the Arabic workspace.
- Salary values outside the organization band receive an explicit review warning.
- Narrow-screen OD controls wrap instead of forcing horizontal overflow.

## Deliberately not claimed

- The bundled occupation corpus remains the supplied 2019 snapshot until a newer official source is ingested and regression-tested as a separate data migration.
- English occupation-title coverage is not complete because the supplied corpus is Arabic-first; a bounded alias layer only supports common review cases.
- Semantic-model availability is not claimed on the production service.
- Salary values are organization-provided bands, not live market benchmarks.
- Miyar does not calculate proprietary Korn Ferry, Mercer or WTW scores.

The regression suite must pass before this branch is merged to `main` and deployed to GitHub Pages / Render.
