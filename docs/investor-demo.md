Open [Miyar](https://adeebnoor.github.io/Miyar/). **Start here** explains the buyer problem and deliverable. **Investor presentation** opens the bilingual seven-slide story. The original five-role views are grouped under earlier examples in the sidebar.

## A focused ten-minute demonstration

| Time | Action | Observable result |
| --- | --- | --- |
| 0–1 min | Show Start here | Business need, defined work and a decision tied to its reviewed version |
| 1–3 min | Complete Guided tour | Four fictional steps: need, reference, independent reviewers and amendment; no approval is created |
| 3–5 min | Open and edit the example | Type any Field and Seniority; edit RACI and competency cells; preview the package |
| 5–6 min | Save locally, revise and open the register | Same identity with a new revision; searchable records, status filters and pagination |
| 6–8 min | Open Value & pilot | Credible comparison, explicit effort assumptions, optional first-year costs and a downloadable four-week plan |
| 8–9 min | Check Service readiness | Current reachability/configuration separated from login, disabled semantic matching and external setup |
| 9–10 min | Agree a bounded partner pilot | Cases, owner, baseline, acceptance targets, implementation effort and willingness to pay |

Search occupation code `251204` to show a source-linked record. JSON import restores editable content as a new draft without trusting imported approvals. HTML and JSON work locally; open downloaded HTML and print it for PDF. DOCX/XLSX/direct PDF, institutional approvals and signed internal receipts require the deployed API and appropriate accounts.

The value calculator starts with **example assumptions**, not customer results. Enter both annual and setup costs, even if zero, for a first-year net estimate. Time released is not automatically cash savings. Downloading a pilot plan does not submit it, register a lead or book a meeting.

## Institutional demonstration

Follow [first-login instructions](render-activation.md). Use synthetic manager, OD, Rewards, Finance and final-authority accounts. Configure an organization-approved custom framework and persistent signing key. Submit a synthetic position and perform each stage under its actual reviewer account. The requester cannot approve their own request. Check export content and history; keep this distinct from the guest guided tour.

Semantic retrieval needs enabled model resources. External integration destinations need authorized endpoints and credentials. No live connection or partnership is implied by a platform name.

Use the [product review](product-investor-review.md) for findings and evidence. Do not claim proven savings, validated population-level matching accuracy, paid customers, certification, an awarded patent or an institutional deployment verified solely by public health checks.
