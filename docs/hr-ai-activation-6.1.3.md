# HR AI activation — 6.1.3

Semantic occupation and skill retrieval uses a pinned, quantized multilingual E5 model on the existing Miyar server. The complete index covers 5,041 public SSCO occupation labels and 37 authored/reference skill descriptions. Docker builds download and verify public model artifacts and precompute the float32 index; incoming descriptions are processed in request memory and are not cached. Runtime needs no model-download credential or external embedding call. ONNX telemetry is disabled before initialization.

The original Gemini full-corpus activation was rejected by the live provider with HTTP 429 after 100 inputs. The original local MiniLM model measured above 512 MiB before API overhead. The E5 adapter uses a single shared session, SentencePiece tokens verified against the reference tokenizer, query/passage prefixes, masked mean pooling, normalization and bounded token chunks preserving long-description tail context. The measured full index is approximately 7.8 MB. Arabic PDF, maximum-chunk and Argon2 measurements verify the memory budget; production readiness must still pass after deployment.

Cosine scores are not confidence. The skill vocabulary and the two authored occupation crosswalks remain limited; absent task profiles and unsupported overlaps stay null. Suggested skills and reference codes require human review. Public labels may be indexed; incoming descriptions are not saved by the public trial. The optional Gemini embedding path retains redacted quota diagnostics and resumable public-corpus checkpoints without bypassing provider limits.

KPI generation explicitly selects the existing server-only Gemini configuration. No credential is copied to frontend bundles, source files or CI fixtures. A strict JSON schema and a second local validator require three to five complete rows. The prompt preserves explicit targets and deadlines, keeps metric/target units consistent and marks inferred targets as proposals. Targets require baseline and manager review. Provider-specific consent identifies local semantic processing or external Google processing before any POST. Organization routes remain authenticated and tenant-scoped; public expert routes retain the existing expiration, origin checks, persisted shared quotas and concurrency controls. They cannot access organizational positions or create approvals.

Arabic and English browser cases exercise UI → real disposable API → deterministic provider boundary, including consent, malformed responses, failure, changed inputs and navigation. They are not live-model accuracy scores. Real model verification measures tokenizer parity, index construction, resource use and live synthetic Arabic/English examples. No production organization credentials are needed for the public review routes.

Source links now point to SOCPA's associate-membership service, the official Umm Al-Qura engineering-practice regulations (clearly labeled as a regulation), and WEF's canonical Future of Jobs 2025 article. The checker includes literal dynamic source URLs and retains denial/timeouts. All 44 current links returned HTTP 200 in the workspace GET check; GitHub's runner confirmed 39 and reported five restrictions/timeouts. Source reachability is evidence for that origin and time, not a promise of universal availability or regulatory currency.
